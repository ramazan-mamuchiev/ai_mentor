# App Icons

Teams manifest requires two icons:

- `color.png` — 192x192 px, full color icon
- `outline.png` — 32x32 px, white outline on transparent background

You can create these using any image editor or online tool.
For a quick start, use https://adaptivecards.io/designer/ or create simple icons with the letter "L" on a purple (#4F46E5) background.

Place the generated PNG files in this directory before creating the app package ZIP.
