## 1. Naming Decision

### 1.1 Final Choice

| Parameter | Value |
|-----------|-------|
| **Brand Name** | **Lexiro** |
| **Decision Date** | March 26, 2026 |
| **Previous Names** | IPCodex (working title) → Plexicode (v1) |

### 1.2 Why Lexiro

**Naming criteria:**

- [x] Short, 1–2 words, up to 10 characters — **Lexiro = 6 characters**
- [x] Melodic pronunciation in Russian and English
- [x] Easy to remember — musical, 3 syllables (LEK-si-ro)
- [x] Energy and character (Figma, Notion, Miro class)
- [x] Minimalistic
- [x] No negative connotations in Russian
- [x] Sounds like a dev-tool, not corporate software
- [x] Conveys simplicity from complexity
- [x] Suggests documentation → code transformation
- [x] Available for trademark registration (Classes 9, 42)

**Evaluated alternatives (v2 round):**

| Name | Score | Verdict | Reason |
|------|-------|---------|--------|
| Plexicode | 6/10 | Rejected | Cyprus shell company (PLEXICODE LTD), GitHub @plexicode occupied, "Plexi" US slang, too long (9 chars) |

## 2. Name Etymology & Semantics

### 2.1 Etymology

```
Lexiro = Lex + iro
         │     │
         │     └── Direction, movement (cf. giro, enviro)
         └──────── Latin "lex" = law, rule, word;
                   Greek "lexis" = word, speech;
                   EN "lexer" = text analyzer, parser
```

**Root meanings:**

| Root | Origin | Meaning | Association |
|------|--------|---------|-------------|
| **Lex** | Latin "lex" | Law, rule, word | Structure, order, knowledge |
| **Lex** | Greek "lexis" | Word, speech, expression | Lexicon, vocabulary, documentation |
| **Lex** | EN "lexer" | Lexical analyzer, text parser | Developer tools, code analysis |
| **-iro** | Romance suffix | Direction, flow, movement | Dynamic action, transformation |

### 2.2 Semantic Interpretation

**Primary meaning:**
> "Directed knowledge" — a platform that channels complex documentation into clear, actionable code answers.

**Alternative interpretations:**

| Interpretation | EN | RU |
|----------------|----|----|
| Directed knowledge | Направленное знание | Знание с направлением |
| Lexical navigator | Лексический навигатор | Навигатор по лексике API |
| Words into action | Слова в действие | Из слов — в код |
| Knowledge flow | Поток знаний | Непрерывный поток знаний |

### 2.3 Phonetic Analysis

| Language | Pronunciation | Syllables | Stress |
|----------|---------------|-----------|--------|
| English | /ˈleksɪroʊ/ | LEK-si-ro | First syllable |
| Russian | /лексиро́/ | ЛЕК-СИ-РО | Last syllable |
| Spanish | /lekˈsiɾo/ | lek-SI-ro | Second syllable |

**Phonetic qualities:**
- 3 syllables — rhythmic, energetic (same class as Figma, Notion, Miro)
- Strong "L" start — confident, professional
- Soft "-exi-" middle — smooth, pleasant
- Open "-ro" ending — dynamic, forward-moving
- Easy to pronounce in EN, RU, ES, DE, FR, PT
- Easy to spell after hearing once
- No problematic consonant clusters

## 5. Brand Story (Legend)

### 5.1 Origin Story

> **The Problem**
>
> Developers integrating physical security and IoT products waste hours reading vendor documentation: 180-page PDFs with no search, scattered Swagger specs, outdated SDK examples. Every new device means days of manual research.
>
> **The Insight**
>
> What if AI could read all that documentation for you? What if your coding assistant already knew every API endpoint, every protocol quirk, every authentication flow — before you even asked?
>
> **The Solution**
>
> Lexiro channels chaotic documentation into a unified knowledge base. It transforms PDFs, Swagger specs, and web pages into structured, searchable intelligence — delivered directly to your AI coding assistant via MCP.
>
> **The Name**
>
> "Lexiro" — from Latin "lex" (law, word, knowledge) and "-iro" (direction, flow). Directed knowledge. Complex docs, simple code.

### 5.2 Mission Statement

| EN | RU |
|----|-----|
| We eliminate the friction between documentation and code, enabling developers to integrate any API in minutes, not days. | Мы устраняем барьер между документацией и кодом, позволяя разработчикам интегрировать любой API за минуты, а не дни. |

### 5.3 Value Proposition

| Audience | Value |
|----------|-------|
| **Developers** | Stop reading manuals. Ask your AI assistant and get working code. |
| **Tech Leads** | Onboard new developers in hours, not weeks. Consistent API knowledge across the team. |
| **CTOs** | Reduce integration time by 70%. Ship faster with fewer bugs. |
| **Vendors** | Make your API documentation AI-ready. Increase developer adoption. |

## 7. Visual Identity (Guidelines)

### 7.1 Logo Concept

**Direction:** Abstract "L" mark suggesting flow/transformation — documentation flowing into code. Minimalist, geometric.

**Style:** Modern, minimal, suitable for dark and light backgrounds. Should feel like Figma/Notion/Miro class.

**Avoid:** Literal representations of documents, PDFs, robots, or books.

### 7.2 Color Palette (Recommended)
