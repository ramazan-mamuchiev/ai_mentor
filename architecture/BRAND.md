| Name | Verdict | Reason |

| **Plexicode** | **Selected** | Unique, melodic, formal, minimal conflicts, strong semantic fit |

**Selection criteria met:**

- [x] Melodic pronunciation in Russian and English
- [x] Formal, suitable for B2B enterprise product
- [x] No negative associations in Russian
- [x] 3 syllables (PLEK-si-kod)
- [x] Strong connection to product meaning
- [x] Available for trademark registration

## 2. Name Etymology & Semantics

### 2.1 Etymology

```
Plexicode = Plex + i + Code
            │     │   │
            │     │   └── Code: programming, source code, integration code
            │     └────── Linking vowel (euphonic connector)
            └──────────── From Latin "plexus" (interwoven, network, connection)
```

**Root meanings:**

| Root | Origin | Meaning | Association |
|------|--------|---------|-------------|
| **Plex** | Latin "plexus" | Interwoven, network, braid | Neural plexus, solar plexus, complex systems |
| **Plex** | English "complex" | Intricate, sophisticated | Complex APIs, complex integrations |
| **Code** | English | Source code, programming | Developer tools, coding assistants |

### 2.2 Semantic Interpretation

**Primary meaning:**
> "The code that weaves together" — a platform that interconnects complex APIs and documentation into unified, accessible knowledge for developers.

**Alternative interpretations:**

| EN | RU |
|----|-----|
| Interwoven Code | Сплетённый код |
| Code Network | Сеть кода |
| Complex Code Simplified | Сложный код — упрощённый |
| The Connecting Code | Связующий код |

### 2.3 Phonetic Analysis

| Language | Pronunciation | Syllables | Stress |
|----------|---------------|-----------|--------|
| English | /ˈpleksɪkoʊd/ | PLEK-si-code | First syllable |
| Russian | /плекси́код/ | ПЛЕК-си-КОД | Last syllable |

**Phonetic qualities:**
- Consonant cluster "pl-" → strong, professional start
- Soft "-exi-" → smooth middle section
- Hard "-code" → technical, precise ending
- No problematic sounds for Russian speakers
- Easy to spell after hearing once

## 5. Brand Story (Legend)

### 5.1 Origin Story

> **The Problem**
>
> Developers integrating physical security and IoT products waste hours reading vendor documentation: 180-page PDFs with no search, scattered Swagger specs, outdated SDK examples. Every new device means days of manual research.
>
> **The Insight**
>
> What if AI could read all that documentation for you? What if your coding assistant already knew every API endpoint, every protocol quirk, every authentication flow — before you even asked?
>
> **The Solution**
>
> Plexicode weaves together chaotic documentation into a unified knowledge base. It transforms PDFs, Swagger specs, and web pages into structured, searchable intelligence — delivered directly to your AI coding assistant via MCP.
>
> **The Name**
>
> "Plexicode" — from Latin "plexus" (interwoven) and "code." The code that weaves together. Complex APIs, simple answers.

### 5.2 Mission Statement

| EN | RU |
|----|-----|
| We eliminate the friction between documentation and code, enabling developers to integrate any API in minutes, not days. | Мы устраняем барьер между документацией и кодом, позволяя разработчикам интегрировать любой API за минуты, а не дни. |

### 5.3 Value Proposition

| Audience | Value |
|----------|-------|
| **Developers** | Stop reading manuals. Ask your AI assistant and get working code. |
| **Tech Leads** | Onboard new developers in hours, not weeks. Consistent API knowledge across the team. |
| **CTOs** | Reduce integration time by 70%. Ship faster with fewer bugs. |
| **Vendors** | Make your API documentation AI-ready. Increase developer adoption. |

## 7. Visual Identity (Guidelines)

### 7.1 Logo Concept

**Direction:** Abstract representation of interconnected nodes/code, suggesting "plexus" (network) and "code" (digital).

**Style:** Modern, minimal, geometric. Suitable for dark and light backgrounds.

**Avoid:** Literal representations of documents, PDFs, or robots.
