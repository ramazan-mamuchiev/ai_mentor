> **✅ Выбранный слоган (hero)**
>
> **EN: "Protocols speak. Codex translates."**
> **RU: "Протоколы говорят. Codex переводит."**
>
> Мелодичная метафора — объясняет *что делает* продукт. Обыгрывает название (IPCodex → Codex),
> точно попадает в суть (протоколы — ONVIF, RTSP, MQTT, HTTP, SOAP), создаёт метафору
> "переводчика" между языком протоколов и кодом разработчика. Аллитерация (speak / translates),
> параллелизм ([субъект] + [глагол] × 2). Подсознательно связывается с "IP" в названии.
>
> **✅ Субтитр (под слоганом)**
>
> **EN: "From docs to code. Instantly."**
> **RU: "Из документации в код. Мгновенно."**
>
> Конкретика и скорость — объясняет *как именно* работает продукт. Ноль повторов
> со слоганом (разные слова = два смысловых слоя). Передаёт трансформацию (docs → code)
> и ключевое преимущество (instantly / мгновенно).
>
> Двухуровневое сообщение: слоган (метафора, мелодика) + субтитр (конкретика, скорость).
>
> *Ранее рассматривался вариант "Many protocols. One Codex." / "Протоколов много — Codex один." —
> отклонён из-за повтора слов "Protocols" и "Codex" в обеих строках.*
>
> Остальные варианты ниже сохранены для справки и возможного использования в маркетинговых материалах.

Анализ позиционирования компаний из [MARKET_RESEARCH.md](MARKET_RESEARCH.md), секции 2.2–2.4.

| Конкурент | Слоган / Tagline | Фокус |

### 1.2 AI Developer Tools

| Конкурент | Слоган / Tagline | Фокус |
|-----------|-----------------|-------|
| **GitHub Copilot** | **"Your AI pair programmer"** + *"Faster, smarter, and built for how you work now"* | AI-помощник в коде |
| **Postman** | **"From Siloed to Synced"** — *"AI-native API Platform"* | Унификация API-процессов |

### 1.3 Выводы из анализа конкурентов

**Паттерны позиционирования:**
- **Инфраструктурные** (Pinecone, Weaviate, Algolia) — говорят о технологии: "vector database", "AI retrieval platform"
- **Документационные** (ReadTheDocs, DevDocs, Mintlify) — говорят о процессе: "docs as code", "documentation browser"
- **AI-инструменты** (Copilot, Postman) — говорят о разработчике: "your AI pair programmer", "AI-native"

**Незанятая ниша IPCodex — ни один конкурент не говорит о:**
- Устройствах / IoT / IP-камерах
- Ускорении интеграции конкретных API вендоров
- Решении проблемы разрозненной документации устройств
- AI как движке интеграции (а не просто поиска или генерации кода)
