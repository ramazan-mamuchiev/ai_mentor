## 1. Слоганы косвенных конкурентов

Анализ позиционирования компаний из [MARKET_RESEARCH.md](MARKET_RESEARCH.md), секции 2.2–2.4.

| Конкурент | Слоган / Tagline | Фокус |

| **Mintlify** | **"The documentation platform of tomorrow"** — *"Documentation that converts users"* | Красивая документация |

### 1.2 AI Developer Tools

| Конкурент | Слоган / Tagline | Фокус |
|-----------|-----------------|-------|
| **GitHub Copilot** | **"Your AI pair programmer"** + *"Faster, smarter, and built for how you work now"* | AI-помощник в коде |
| **Postman** | **"From Siloed to Synced"** — *"AI-native API Platform"* | Унификация API-процессов |

### 1.3 Выводы из анализа конкурентов

**Паттерны позиционирования:**
- **Инфраструктурные** (Pinecone, Weaviate, Algolia) — говорят о технологии: "vector database", "AI retrieval platform"
- **Документационные** (ReadTheDocs, DevDocs, Mintlify) — говорят о процессе: "docs as code", "documentation browser"
- **AI-инструменты** (Copilot, Postman) — говорят о разработчике: "your AI pair programmer", "AI-native"

**Незанятая ниша IPCodex — ни один конкурент не говорит о:**
- Устройствах / IoT / IP-камерах
- Ускорении интеграции конкретных API вендоров
- Решении проблемы разрозненной документации устройств
- AI как движке интеграции (а не просто поиска или генерации кода)
